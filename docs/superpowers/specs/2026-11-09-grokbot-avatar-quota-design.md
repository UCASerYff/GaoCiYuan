# Grok Bot 头像栏目额度读取设计

日期：2026-11-09  
目标版本：搞词元 4.12（构建 13）

## 目标

Grok Bot 不再通过 `grokbot-usage.json` 获取新读数，改为与 Kimi 等现有本机桌面连接器相同的辅助功能路径：按下 Grok Bot 左下角头像，从账户栏目读取套餐与已用百分比，悬浮圆环显示剩余百分比。手动同步立即读取；自动刷新在 Grok Bot 未被前台操作时也会读取。

当前真实界面已确认栏目项形如 `Premium 96% 已用`，应保存为已用 96%、展示为剩余 4%。

## 方案边界

- 新增独立的 `GrokBotAX` 本机读取层，复用 `AXShared` 的受限遍历方式。
- 手动同步允许立即读取和导航，按钮文案改为“读取本机额度”，不受自动导航节流限制。
- 自动刷新仅在 Grok Bot 非前台时读取；栏目未展开时，按账户执行 5 分钟导航节流。前台使用中跳过自动读取并保留上次数据，不抢焦点、不打扰输入。
- 若栏目已经展开且允许本次读取，直接读取，不重复点击；只有本次读取打开的栏目才在结束后用直投 Escape 收起。
- 未运行、未授权辅助功能、头像缺失、栏目未出现或额度格式变化时给出明确状态或错误，并保留上次成功读数。自动读取失败只形成状态，不制造账户告警；手动读取失败提供可操作原因。
- 不发起网络请求，不读取聊天、Cookie、凭证或 Grok Bot 私有数据库，不点击套餐、设置、退出登录等菜单项。

## 解析与数据流

1. 从窗口最下方、靠左且带标题的 `AXPopUpButton` 中定位头像，避免命中“分享”或“输入框操作”。
2. 只接受完整匹配 `<套餐> <0...100 数字>% 已用` 的栏目文本；支持整数和小数，拒绝剩余量、越界值、非有限值及多个互相冲突的候选。
3. 成功读取后以当前时间为 `capturedAt`，保存套餐、已用百分比和来源类型；`resetsAt` 为 `nil`，不沿用旧快照重置时间，也不声称栏目提供了共享范围。
4. `ManualReading` 以可选字段扩展以保持存档兼容，旧记录继续按历史快照口径展示，新记录明确标记为头像栏目来源；类型和既有 `ConnectorResult`  case 名称仅为兼容保留，不代表只能手动读取。
5. 新记录的状态文案使用“额度剩余 X%（已用 Y%）”，包含套餐和采集时间，不写“本周剩余”或未提供的重置时间。圆环标签仅为剩余百分比，过期仍靠灰色、透明度和说明区分。
6. 成功读取替换旧读数；失败不制造 0% 或 100%，也不清除上次成功记录。
