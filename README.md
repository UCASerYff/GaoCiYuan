# 搞词元 V4.13

独立 macOS Agent 软件额度与用量管理应用，包含紧凑总览、Agent 软件管理、用量分析、平台接入和悬浮窗。运行不依赖其他搞系列应用；第三方数据读取需要对应软件及本机现有登录状态。

## 下载与安装

从 [Releases](https://github.com/UCASerYff/GaoCiYuan/releases/latest) 下载 `GaoCiYuan-4.13.zip` 和同名 `.sha256` 文件。仓库保存源码，安装包作为 Release 附件单独发布。

1. 支持 macOS 14 或更高版本、Apple Silicon；暂未提供 Intel 版本。
2. 解压 ZIP，将 `搞词元.app` 拖入“应用程序”文件夹。
3. 如果 macOS 拦截打开，请先确认软件来源，再进入“系统设置 → 隐私与安全性”，允许该应用打开。发行包使用 Apple Development 签名，未做 Apple 公证。
4. 安装后运行一次，真实 Agent 账户、用量分析数据库及悬浮窗设置会继续沿用。旧 LLM 与自定义 API 账户会永久删除；桌面和通知中心小组件不再提供。

下载后可在文件所在目录运行 `shasum -a 256 -c GaoCiYuan-4.13.zip.sha256` 核验安装包。

## 功能

- 四页紧凑顶部导航：总览、Agent 软件、用量分析、平台接入；支持动态深浅色和浮动面板。
- 只管理 Agent 软件及其真实额度、账单连接和本地用量，不再区分大模型与 Agent，也不新增大模型 API 或自定义 API 余额账户。
- 按工具、模型、时间等维度查看词元消耗；对重复日志和跨来源记录进行核对。
- 内置 Tokscale 扫描引擎及本地修订，版本与源码补丁位于 `Resources/UsageEngine`。
- 从菜单或 ⌘, 打开设置，提供外观、数据来源和 CSV／用量 JSON 导出；不提供完整资料备份或恢复。

## 用户数据、附件与隐私

源码及安装包不包含个人记录、账户配置、账单、私人附件、API 密钥、浏览器会话或用户备份。新电脑首次打开时创建自己的资料库；GitHub 下载不能恢复个人数据。

- 业务数据目录：`~/Library/Application Support/GaoSeries/Token/`。
- 兼容共享数据目录：`~/Library/Group Containers/5G96498KGJ.com.gaoseries.GaoCiYuan/`。
- 设置保存在本应用的 UserDefaults 域；真实 Agent 凭据继续由 macOS 钥匙串管理。
- 公开安装包会删除本机编译路径、源文件索引及扩展属性，再重新签名。签名证书的公开身份信息随软件发布，签名私钥不在仓库或安装包中。

真实 Agent 业务历史与用量分析继续保存在原位置。界面采用分页或归档减轻加载；累计用量、费用、余额与用量账本独立保存。

## 数据迁移与无备份政策

升级或替换应用程序不会删除真实 Agent 历史、用量分析、设置和附件。V4.13 启动时永久删除旧 LLM／自定义 API 账户及其专属钥匙串凭据，不创建迁移副本。

自 V4.13 起，应用、更新器与安装脚本均不创建或保留自动备份、手动完整资料备份、升级快照、旧程序回滚包或 Claude 配置滚动备份。既有备份由本次升级精确清理；安装失败时停止并报告，不自动恢复。无备份政策不影响上述现用业务资料。

## 从源码构建

需要完整 Xcode、Python 3 和 Apple Silicon Mac。默认脚本使用项目配置的开发签名身份；自行构建需使用自己的 Apple Development 证书，并相应调整签名团队、App Group 权限。

```sh
./scripts/build.sh
./scripts/package.sh
./scripts/install.sh
```

通过环境变量 `GAO_SIGNING_IDENTITY` 可指定签名证书。修改团队后也需调整 `scripts/install.sh` 中的团队检查。`dist/` 只存放最新版发行 ZIP 和校验文件，不提交到 Git；上传到 GitHub Releases。

- `Sources/` 与 `Module.swift`：Agent、采集、分析和界面逻辑。
- `Resources/`：图标、平台资源、翻译与 Tokscale 扫描引擎。
- `Host/`：独立入口、设置和联动服务。
- `Tests/`：离线及隔离回归验证。
