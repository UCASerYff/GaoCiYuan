# 搞词元 V4.13 紧凑界面与 Agent 平台重构设计

## 目标与范围

本轮只修改搞词元：缩小主窗口与留白，重做为紧凑顶部导航；删除“用量记录”页面；停止大模型 API 账户的新增、展示和采集，只围绕 Agent 软件管理额度与本地用量；删除旧 LLM API 账户数据；移除应用备份创建、恢复和自动滚动备份功能。悬浮窗、菜单栏、现有 Agent 连接器、用量分析和其他真实用户资料继续保留。

## 界面设计

- 使用暖灰画布、墨青主文字和青绿强调色，深色外观使用对应动态颜色；不沿用其他搞系列 App 的视觉模板。
- 取消 236 pt 宽侧栏，改为紧凑品牌区和顶部导航。四个栏目为“总览”“Agent 软件”“用量分析”“平台接入”。
- 主窗口最小尺寸从 1020×680 收紧到约 880×560；页头、卡片、统计块、按钮和网格间距同步收紧，减少无信息留白。
- 总览只统计 Agent 软件，不再出现 LLM API 统计卡、添加 API 账户入口或 API 专属说明。
- 删除“用量记录”栏目及其页面图表；Agent 的既有历史快照仍留在原数据库，并继续供额度变化和分析逻辑使用。
- 保留账户搜索、告警定位、同步、账户编辑、悬浮窗与菜单栏交互。

## 平台与数据口径

- 平台页统一展示 Agent 软件目录和本地用量采集来源，不再按“大模型／Agent”分组，也不提供 API 账户或自定义 API 余额入口。
- 仅允许创建 `AccountKind.agent` 账户；纯 LLM 平台不再出现在新增目录中。旧枚举和解码器可保留用于一次性迁移，但不能从界面、自动发现、刷新或悬浮窗进入新的 API 采集路径。
- 首次运行新版时执行无备份迁移：从资料库永久删除全部 `AccountKind.llm` 账户及其快照、历史、预算和配置，并删除这些账户专属钥匙串凭据。Agent 账户及用量分析所需的本地 Token、模型、会话记录不在删除范围内。
- 迁移后直接写回原资料路径，写失败则停止并报告，不创建空库或备份。后续版本不再保留 LLM 展示与采集入口。
- 现有 Agent 数据继续使用 `~/Library/Application Support/GaoSeries/Token/`、App Group 和原钥匙串服务，不改变 Bundle ID。

## 备份移除与资料保护

- 删除完整资料备份、模块备份、导入恢复菜单、设置入口、文件类型注册及相关实现和回归测试。
- Claude Code 状态栏接入不再创建或轮换 `settings.json` 备份；断开时只恢复本应用明确管理的命令链，不依赖备份副本。
- 本轮更新不创建安全备份、升级快照或回滚副本。构建或安装失败时停止并报告，不生成新的备份。
- 精确删除搞词元既有应用备份、项目回滚副本、旧安装包和中间构建；保留 Agent 业务数据库、账户记录、用量历史、设置、附件与对应钥匙串凭据，不删除来源不明的用户文件。

## 错误处理与兼容性

- 资料读取失败继续禁止空白覆盖，错误文案不再引导用户从备份恢复。
- 旧存档必须能正常解码并完成一次性 LLM 删除迁移；迁移后资料库只含 Agent 账户。
- 已失效的旧页面 SceneStorage 值回落到总览；旧备份 deep link 不再触发恢复。
- 网络或本机读取失败沿用现有真实快照保留策略，不生成虚假额度。

## 验证与发布

- 增加回归验证：四个栏目、无 LLM／用量记录入口、仅 Agent 可新增与刷新、旧 LLM 账户与专属凭据删除且 Agent 数据不变、备份入口及实现不可达。
- 运行相关单元／源码回归和完整构建，检查签名、Bundle ID、版本 V4.13、构建号 14。
- 启动新版核对主要 Agent 账户、用量分析、悬浮窗和资料文件数量／摘要；不自动登录第三方服务，不制造付费调用。
- 确保 Spotlight 与 LaunchServices 只有 `/Applications/搞词元.app` 一个有效入口；测试窗口随用随关。
- 成功后删除旧 App、旧安装包、项目内回滚和中间构建，仅保留最新发行 ZIP 与 SHA256；提交并推送源码，更新对应 GitHub Release，不上传用户数据或备份。
