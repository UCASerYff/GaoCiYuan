# 搞词元 V4.03

独立 macOS AI 额度与用量管理应用，包含账户管理、采集分析和悬浮窗。运行不依赖搞七廿三或其他六个应用；联动功能需要同时安装相关应用。

## 下载与安装

从 [Releases](https://github.com/UCASerYff/GaoCiYuan/releases/latest) 下载 `GaoCiYuan-4.03.zip` 和同名 `.sha256` 文件。仓库保存源码，安装包作为 Release 附件单独发布。

1. 支持 macOS 14 或更高版本、Apple Silicon；暂未提供 Intel 版本。
2. 解压 ZIP，将 `搞词元.app` 拖入“应用程序”文件夹。
3. 如果 macOS 拦截打开，请先确认软件来源，再进入“系统设置 → 隐私与安全性”，允许该应用打开。发行包使用 Apple Development 签名，未做 Apple 公证。
4. 安装后运行一次，原有账户、用量账本及悬浮窗设置会继续沿用。V4.02 不再提供桌面或通知中心小组件。

下载后可在文件所在目录运行 `shasum -a 256 -c GaoCiYuan-4.03.zip.sha256` 核验安装包。

## 功能

- 管理 AI 账户、余额、额度与用量，支持本地日志统计和多种在线连接方式。
- 按工具、模型、时间等维度查看词元消耗；对重复日志和跨来源记录进行核对。
- 内置 Tokscale 扫描引擎及本地修订，版本与源码补丁位于 Resources/UsageEngine。

- 从菜单或 ⌘, 打开设置，提供外观、模块设置、备份与恢复。
- 保留悬浮窗与菜单栏状态显示。

## 用户数据、附件与隐私

源码及安装包不包含个人记录、账户配置、账单、健康数据、私人附件、API 密钥、浏览器会话或用户备份。新电脑首次打开时创建自己的资料库；GitHub 下载不能恢复个人数据。

- 业务数据目录：`~/Library/Application Support/GaoSeries/Token/`。
- 兼容共享数据目录（保留旧镜像及备份兼容性）：`~/Library/Group Containers/5G96498KGJ.com.gaoseries.GaoCiYuan/`。
- 设置保存在本应用的 UserDefaults 域；凭据由 macOS 钥匙串管理，不导出到普通备份文件。
- 公开安装包会删除本机编译路径、源文件索引及扩展属性，再重新签名。签名证书的公开身份信息随软件发布，签名私钥不在仓库或安装包中。

真实业务历史完整保留。界面采用分页或归档减轻加载；每个词元账户显示采样最多 300 条；累计用量、费用、余额与用量账本独立保存。

## 数据迁移与恢复

独立应用继续使用原有数据目录，升级或替换应用程序不会删除业务历史、余额、累计统计、设置和附件。V4.01 不再保留空间站游戏状态。

在设置的数据页导出“完整资料 ZIP 备份”。恢复备份可迁移本应用的资料、App Group 镜像、设置以及已管理的 PDF、Word、照片等附件。备份使用逐文件 SHA-256 校验与 SQLite WAL 一致快照，恢复前保存安全副本；待下次启动应用时应用恢复。备份必须来自同一应用，不能将另外一个模块的备份直接导入。钥匙串凭据需在新电脑重新配置。

迁移临时副本不属于程序运行依赖，确认数据与附件完整后可自行清理。个人备份应单独保管，不应放进源码目录或上传公开仓库。

## 从源码构建

需要完整 Xcode、Python 3 和 Apple Silicon Mac。默认脚本使用项目配置的开发签名身份；自行构建需使用自己的 Apple Development 证书，并相应调整签名团队、App Group 权限。

```sh
./scripts/build.sh
./scripts/package.sh
./scripts/install.sh
```

通过环境变量 `GAO_SIGNING_IDENTITY` 可指定签名证书。修改团队后也需调整 `scripts/install.sh` 中的团队检查。`dist/` 存放本地发行 ZIP 和校验文件，不提交到 Git；上传到 GitHub Releases。

- `Sources/` 与 `Module.swift`：账户、采集、分析和界面逻辑。
- `Resources/`：黑底白字图标、平台图标、翻译与 Tokscale 扫描引擎。
- `Host/`：独立入口、设置、完整备份和联动服务。
- `Tests/`：回归验证。

## 版本更新

版本以 `Info.plist` 为准。后续功能改动仅更新受影响的应用，默认版本 +0.01、构建号 +1；明确要求保持版本号的修订沿用原版本。先核验用户资料，再安装新程序并检查账户、历史用量、累计统计和附件，成功后清理旧程序、安装包与中间构建。程序资源与用户资料须分别处理，不能用清理构建目录的方式删除用户数据。

第三方组件和资源保留各自许可，详情见 `Resources/` 中的许可、来源说明与补丁记录。
